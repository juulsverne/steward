## Fixes made during the walk

- Issue Detail requested 100 events; the API caps the page at 50 and answered 422. Now 50 with a note when the page is full.
- The Inbox only fetched pending and decided exceptions; handled and cancelled items are now fetched too.
- A network failure while polling after a saved operator decision was shown as "Request not saved"; the save now stays visible with a separate warning.
- The Board threw on an unexpected payload; it now renders the empty state.
- Copy: humanized source roles and category, readable conflict state, timeline oldest first, no "observed Unknown" caption in the Inbox, rework notice only while rework is required, board row copy after payment.
- Final review fixes: map popup and tooltip built from DOM nodes instead of HTML strings, reduced-motion rule no longer collapses the map, no focusable controls inside the hidden map canvas, the map fits its bounds once instead of on every refresh, idempotency keys work on non-secure origins, the timeline note says "50 most recent", step badges on the crew page use the active tone, and the traversal test now exercises several escape shapes.

## Known limits

- Static assets are served with `Cache-Control: no-store` because the transport middleware sets it on every response.
- The Board polls every 20 s while visible; other pages refresh on action.
- The live Inbox action was not exercised on screen against a run paused at the pending exception; it is covered by unit tests and the driver's operator step.
